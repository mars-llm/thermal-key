What Thermal Key can do

Everything you need to run a small farm or a single miner without vendor software.

Monitor

Check hashrate, temperature, and power. Read-only JSON snapshots are available for Avalon Q. Missing readings make the health score unavailable; detected alerts still show.

Control

Change fan speed, set mining modes, tune frequency, and reboot. Check settings for your device first.

Automate

Script pool switching, night mode, or heater mode with cron or any scheduler.

Fleet manage

Target dozens of IPs in one command with clean, ordered output.

Recover

Generate auth cookies and retrieve hashes if the web UI locks you out.

Quick start

Install once, then control any miner on your network.

git clone https://github.com/mars-llm/thermal-key.git
cd thermal-key

python3 thermal.py -H 192.168.1.100 status
python3 thermal.py -H 192.168.1.100 watch

Command map

Daily controls in a single script. Use one IP or a fleet list.

Status + Pools

thermal.py -H IP status thermal.py -H IP pools

Fan + Mode

thermal.py -H IP fan 80 thermal.py -H IP mode 1

Performance

thermal.py -H IP freq 500 thermal.py -H IP level 3

Fleet

thermal.py -H ip1,ip2,ip3 reboot thermal.py -H miners.txt status

Reliability

thermal.py --retries 2 --backoff-ms 200 --jitter-pct 20 -H IP status thermal.py --log-jsonl run.jsonl -H ip1,ip2 mode 2 thermal.py --no-preflight -H ip1,ip2 fan 80

Auth + Recovery

thermal.py -H IP auth PASS thermal.py -H IP getauth

Avalon Q Controls

Q modes: 0 = Eco, 1 = Standard, 2 = Super.

thermal.py -H IP work-mode-level 1 2 thermal.py -H IP voltage 2250 thermal.py -H IP solo on thermal.py -H IP loop thermal.py -H IP timezone thermal.py -H IP qinfo

Avalon Q JSON Telemetry

Hashrate, uptime in minutes, temperatures, fans, work mode, and share counters. Missing optional readings are null.

python3 telemetry.py --host IP python3 telemetry.py --host IP --timeout 3

Raw API

thermal.py -H IP raw COMMAND thermal.py -H IP ascset "0,..."

Safety and security

Miners can overheat or be damaged by unsafe settings. Use conservative limits and monitor temperatures.

CGMiner API warning The CGMiner API on port 4028 has no authentication. Anyone on your network can control your miner. Recommended: isolate miners on a VLAN, firewall port 4028, and use strong web UI passwords. Auth and recovery commands redact sensitive hashes/cookies by default. Use --show-secrets only when needed. Recovery prints candidate passwords. A hash match does not prove the original password; verify it before relying on it.
